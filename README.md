# Project Busker

I promised I would build my daughter a busking amp for her Birthday. That was 18 months ago 😫
This project is based on the excellent hackaday article from David Silverman (details below).
The final plan is for a self-contained busking amp with the following features:
- 2 XLR microphone inputs, each with it's own pre-amp and reverb module.
- An electric guitar amp with effects, built using a raspberry pi 4 with an AudioInjector hat
- A hardware mixer
- a power amp
